# 苏格拉底之问

以真实科学研究史为线索的中文单机探索游戏，面向大学一年级学生及对科学方法感兴趣的读者。

**[进入游戏](https://yaoyuzhang1.github.io/socrates-question/)**

两项调查相互独立，可以按任意顺序选择：

- **恐龙灭绝**：从古比奥岩层的原始问题，追踪铱异常、撞击痕迹、陨坑、年代与生态机制之间的证据联系。
- **让mRNA成为药物**：跟随Katalin Karikó与合作者，经历原始动机、核苷修饰、表达机制、转录杂质、递送与疫苗试验。

每关8个研究节点，包含背景、人物、术语、研究材料与原文链接。玩家先留下预期，再比较材料、检查解释的边界，最后整理自己的证据链。原始研究图片可放大阅读，配有中文图注。预期不判对错，自由笔记不自动判分。

## 保存与离线使用

游戏不需要登录，也不上传玩家的研究记录。两关分别保存在当前浏览器；重新开始只清除所选关卡。可以在游戏中导出文字研究记录。

下载本仓库的 `index.html` 后可直接在浏览器中打开，游戏脚本、样式和9张研究图已内嵌。打开外部论文链接需要网络。在线与离线版本、不同浏览器的存档可能彼此独立；清除浏览器数据也会清除本机进度。

## 来源与许可

本项目供免费、非商业的科学教育与学习使用。中文材料是依据原论文、同期报告和参与者回顾的教学重建，并非虚构的历史人物逐字对白。论文阅读链接和推断边界标注在对应材料中。

- 研究图片的署名、原作及各自许可见 [CREDITS.md](CREDITS.md)，并保留在游戏内。图片包含不同许可，请逐项遵守相应条款。
- 浏览器组件的著作权和开源许可全文见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。
- 本仓库用于发布这两个科学探索关卡，不包含其他游戏、个人试玩记录或登录凭据。

## 网页发布

本仓库为独立静态发布包，GitHub Pages 从 `main` 分支根目录发布。`index.html` 为完整游戏，`.nojekyll` 保持静态文件原样提供。无需后端、数据库或API密钥。
