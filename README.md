# 苏格拉底之问

以真实科学研究史写成的中文互动故事，面向大学一年级学生及对科学方法感兴趣的读者。

**[进入游戏](https://yaoyuzhang1.github.io/socrates-question/)**

两项调查相互独立，可以按任意顺序选择：

- **薄层之下 · 恐龙灭绝**：他们只是想知道一层薄泥积了多久，测量结果却把他们带向了一场没有现场的灾难。
- **一封引起警报的信 · Karikó与mRNA**：她想让细胞制造药物，细胞收到指令，却传来了意料之外的回声。

每篇8章、16幕。在连续阅读中跟随人物遇见问题，在转折处选择先追哪条线索。不同调查会带回不同记录，也可以直接跟随研究者继续。没有必填作答或分数门槛；所得线索自动收入手记，随时可以重访已读部分。

关键科学概念随故事出现，名词解释、完整研究者名单、原论文和史实说明放在可展开的史料札记中。9张研究图片保留中文图注、原作署名与许可，可放大阅读。

## 保存与离线使用

游戏不需要登录，也不上传玩家的调查记录。两篇故事分别保存在当前浏览器；重新开始只清除所选故事。可以在“我的线索”中导出调查手记。原研究版的存档不会被覆盖，新故事使用独立书签。

下载本仓库的 `index.html` 后可直接在浏览器中打开，游戏脚本、样式和9张研究图已内嵌。打开外部论文链接需要网络。在线与离线版本、不同浏览器的存档可能彼此独立；清除浏览器数据也会清除本机进度。

## 来源与许可

本项目供免费、非商业的科学教育与学习使用。中文故事依据原论文、同期报告和参与者回顾写成；场景串联与比喻经过文学处理，不冒称历史人物逐字对白。关键研究结果、并行工作与事后回查的年代，接受史料约束。选择改变调查阅读的方向，不改变历史实验结果。

- 研究图片的署名、原作及各自许可见 [CREDITS.md](CREDITS.md)，并保留在游戏内。图片包含不同许可，请逐项遵守相应条款。
- 浏览器组件的著作权和开源许可全文见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。
- 本仓库用于发布这两个科学探索关卡，不包含其他游戏、个人试玩记录或登录凭据。

## 网页发布

本仓库为独立静态发布包，GitHub Pages 从 `main` 分支根目录发布。`index.html` 为完整游戏，`.nojekyll` 保持静态文件原样提供。无需后端、数据库或API密钥。
