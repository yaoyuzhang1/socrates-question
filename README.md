# 苏格拉底之问

以真实科学研究史写成的中文图像推理故事，面向大学一年级学生及对科学方法感兴趣的读者。

**[进入游戏](https://yaoyuzhang1.github.io/socrates-question/)**

两项调查相互独立，可以按任意顺序选择：

- **薄层之下 · 恐龙灭绝**：他们只是想知道一层薄泥积了多久，测量结果却把他们带向了一场没有现场的灾难。
- **一封引起警报的信 · Karikó与mRNA**：她想让细胞制造药物，细胞收到指令，却传来了意料之外的回声。

每篇8章、48个图文小页，每页只推进一件事。两篇合计36处推理：根据当时掌握的证据选择一个最佳答案。答错出现红色提示和短动画，播放所选选项的解析，再由玩家重新作答；答对后出现绿色确认动画和不同提示音，才可继续。查看提示不会直接通关。每个选项都有解析，108条普通话配音随游戏内嵌，可以随时停止、重播或关闭声音。把调查推进到深处的关键追问，会单独突出并收入线索本。

恐龙篇的调查由异常读数转向撞击，最终拼合事件、物质来源与年代三条证据；mRNA篇在修饰样品仍有反应时回查瓶内组成，通过分离与对照逐步揭晓原因，再走到人体试验。

两篇共96幅逐页叙事插画，人物和画风连续；每次放大只看当前一格。另保留25张科学照片、图解和研究图片，资料默认折叠并注明可能涉及后文。名词解释、完整研究者名单、原论文和详细背景可以按需展开。生成插画与真实照片、实测数据及原论文图件明确区分，原始资料保留独立来源、许可和用途说明。

## 保存与离线使用

游玩不需要登录，成绩和书签默认只保存在本机。两篇故事分别保存进度；重新开始只清除所选故事。可以在“线索本”中导出或直接复制调查笔记。先前版本的存档仍然保留。

同一故事在多个标签页打开时，会同步已经取得的线索和可回访的页；回看不会删掉另一标签页的调查记录。旧版图像故事书签会自动迁移。如果浏览器暂时无法保存，游戏会明确提示，并在当前页面会话中暂存两篇故事的进度；刷新或关闭前请导出笔记。

下载本仓库的 `index.html` 后可直接在浏览器中打开，游戏脚本、样式、96幅插画所用的6张无损画稿、25张科学图像及108条解析配音已内嵌，约42.7 MB。配音在选择答案后开始，无需连接在线语音服务；浏览器阻止播放时可点击“重播解析”。翻页、打开资料或离开当前标签会停止配音，声音不会影响答题和通关。打开外部论文链接需要网络。在线与离线版本、不同浏览器的存档可能彼此独立；清除浏览器数据也会清除本机进度。

## 成绩、排行榜与评论

每关结束显示百分制成绩、评价、首次独立答对／纠错后答对／借助提示掌握的题数，并列出值得回看的推理。每题等权：首次独立答对计100%题分，纠错后答对计60%，使用提示后答对计30%；最后换算为百分制、四舍五入。不以阅读速度计分，听解析、读史料不扣分。

旧版记录继续保留；已通关且能还原全部作答结果的显示“参考成绩”，可以直接提交，投稿与榜单标注“旧版参考”。不虚构缺失的过程记录；同一账号同分时优先保留完整新记录。缺少部分答案的旧记录仍保留通关与线索，重新挑战可获得完整新成绩。

书架和关末均可打开排行榜；已通关的故事也可从书架“查看成绩与提交”返回成绩页。两关分别排名，同一GitHub账号每关保留最高成绩，同分并列。榜单用于玩家交流，属于自报学习记录，不是经过监考的考试成绩。

玩家可自愿填写昵称、星级和评论，先预览草稿，再登录GitHub确认发布。只有主动发布的内容才进入社区；游戏不会上传其他本机书签、笔记或登录凭据。发布后，GitHub账号、所填昵称、成绩和评论会公开显示。关闭自己的投稿，可在下次更新中从榜单撤回；如果还有先前未关闭的投稿，系统会重新取其中的最高成绩／最近评论。原帖仍遵循GitHub的保留规则。

排行与评论由本仓库的公开Issues自动生成，通常需几十秒至几分钟处理。打开榜单、从GitHub返回和联网恢复时会重新读取数据，榜单窗口显示时每20秒自动检查一次，并显示榜单更新与本次检查的时间。书架优先打开最近完成关卡的榜单；两关空榜提示也会明确说明所选关卡。查看或提交社区内容需要联网。管理员可关闭投稿或添加`community-hidden`标签进行管理。规则与维护方法见 [社区说明](community/README.md)。

## 来源与许可

本项目供免费、非商业的科学教育与学习使用。中文故事依据原论文、同期报告和参与者回顾写成；场景串联与比喻经过文学处理，不冒称历史人物逐字对白。关键研究结果、并行工作与事后回查的年代，接受史料约束。“最佳答案”只针对题目给定的证据与任务，不表示真实科学探索只有唯一道路，也不改变历史实验结果。

- 研究图片的署名、原作及各自许可见 [CREDITS.md](CREDITS.md)，并保留在游戏内。图片包含不同许可，请逐项遵守相应条款。
- 浏览器组件的著作权和开源许可全文见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。
- 本仓库用于发布这两个科学探索关卡，不包含其他游戏、个人试玩记录或登录凭据。

## 网页发布

本仓库为独立静态发布包，GitHub Pages 从 `main` 分支根目录发布。`index.html` 为完整游戏，`.nojekyll` 保持静态文件原样提供。社区更新由 GitHub Actions 处理，无需自行部署服务器、数据库或配置 API 密钥。
